## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd birthday-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:3000`

## 🎨 Customization

### Personal Content
1. **Update the intro message** in `app/page.tsx` - modify the heartfelt message to your partner
2. **Change the birthday date** in the CountdownTimer component
3. **Add your photos** to the timeline in `components/Timeline.tsx`
4. **Customize colors** in `app/globals.css` and `tailwind.config.ts`

### Timeline Memories
Edit the `timelineData` array in `components/Timeline.tsx`:
```typescript
const timelineData = [
  {
    id: 1,
    date: "Your Date",
    title: "Your Title",
    description: "Short description",
    image: "https://your-image-url.jpg",
    location: "Location",
    details: "Detailed story..."
  },
  // Add more memories...
];
```

### Background & Music
1. **Background image**: Replace the Pexels URL in `app/page.tsx`
2. **Background music**: Add your music file as `public/birthday-song.mp3`
3. **Custom fonts**: Update font imports in `app/layout.tsx`

## 🎵 Music Setup

1. Add your birthday song as `public/birthday-song.mp3`
2. Ensure the file is compressed for web (MP3, under 5MB recommended)
3. The music will auto-loop and respect user preferences

## 🌐 Database Setup (Optional)

For persistent messages, set up Supabase:

1. Create a Supabase project at [supabase.com](https://supabase.com)
2. Create a `.env.local` file:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```
3. Create the messages table in Supabase:
```sql
create table messages (
  id bigint generated by default as identity primary key,
  name text not null,
  message text not null,
  email text,
  timestamp timestamp with time zone default timezone('utc'::text, now()) not null,
  approved boolean default false,
  likes integer default 0
);
```

## 🚀 Deployment

### Vercel (Recommended)
1. Push your code to GitHub

3. Add environment variables if using Supabase

3. Configure environment variables in Netlify dashboard

## 🐛 Troubleshooting

### Common Issues:
1. **Music not playing**: Browsers require user interaction before audio
2. **Images not loading**: Check image URLs and CORS policies
3. **Animations stuttering**: Enable GPU acceleration in browser
4. **Mobile scroll issues**: Ensure touch-action CSS is properly set
